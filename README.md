## 📖 About The Game

> *"You volunteered for what you thought was a simple experiment. Now you're trapped in a facility where nothing is as it seems. Your only way out is through."*

**The Test Subject** is a first-person puzzle adventure game where you play as a volunteer trapped in a mysterious testing facility. Solve puzzles, navigate challenging environments, and uncover the secrets behind the experiments. Your wits and observation skills are your only tools for survival and escape.

### ✨ Features

- 🧩 **Challenging Puzzles** — Environmental puzzles that require creative thinking and keen observation
- 🏢 **Mysterious Facility** — Explore a detailed testing facility with secrets around every corner
- 📜 **Engaging Story** — Uncover the truth behind the experiments through environmental storytelling
- 🎮 **Smooth Controls** — Intuitive first-person controls optimized for immersive gameplay

## 🎮 Quick Start

### For Players

1. **Download and Extract:**
   - Navigate to the `Game-files` folder in this repository
   - Run `The Test Subject.exe`
   - No installation required—just double-click and play!

2. **Game Controls:**

| Control | Action |
|---------|--------|
| **WASD** | Move around |
| **Mouse** | Look around / Aim |
| **E** | Interact / Use objects |
| **Space** | Jump |
| **Esc** | Pause / Menu |

3. **Objective:**
   - Explore the facility and solve environmental puzzles
   - Find clues to progress through each level
   - Pay attention to your surroundings—some solutions require creative thinking!

### 💡 Tips

- Take your time to explore every room thoroughly
- Look for visual clues and patterns in the environment
- Some puzzles require multiple steps to solve
- Save your progress frequently using the menu

## 👨‍💻 Developer Setup

Want to contribute or modify the game? Follow these steps to get started:

### Prerequisites

- **Unity Editor** `2022.3.47f1` (recommended for best compatibility)
- **Git** for version control
- **Visual Studio** or **VS Code** (for C# scripting)
- Basic knowledge of Unity and C#

### Installation

1. **Clone the repository:**

```bash
git clone https://github.com/norakjed/The-Test-Subject-game.git
cd The-Test-Subject-game
```

2. **Open in Unity:**
   - Launch Unity Hub
   - Click "Add" and select the `UnityProject` folder
   - Open the project with Unity `2022.3.47f1`

3. **Install Required Packages:**
   
   Open Unity Package Manager (`Window → Package Manager`) and install:
   - **Cinemachine** — Advanced camera system
   - **ProBuilder** — Level design tools
   - **Text Mesh Pro** — Enhanced text rendering

4. **Run the Game:**
   - Open the main scene in the `Assets/Scenes` folder
   - Press the Play button in Unity Editor
