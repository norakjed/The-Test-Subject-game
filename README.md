
# The Test Subject

## Game Introduction

**The Test Subject** is a first-person puzzle adventure game where you play as a volunteer trapped in a mysterious testing facility. Solve puzzles, navigate challenging environments, and uncover the secrets behind the experiments. Your wits and observation skills are your only tools for survival and escape.

## How to Play

1. **Download and Extract:**
	- If you just want to play, go to the `Game-files` folder and run `The Test Subject.exe`.
	- No installation is required—just double-click the executable.

2. **Controls:**
	- **WASD**: Move
	- **Mouse**: Look around
	- **E**: Interact / Use objects
	- **Space**: Jump
	- **Esc**: Pause/Menu

3. **Objective:**
	- Explore the facility, solve environmental puzzles, and find clues to progress through each level.
	- Pay attention to your surroundings—some solutions require creative thinking!

## Project Structure

- `UnityProject/` — Source project for developers and contributors. Open this folder in Unity to view or modify the game's core assets, scripts, and scenes.
- `Game-files/` — Pre-built game for players. Contains the executable and all required runtime data.

## Developer Setup (Unity)

To open and run the project in the Unity Editor:

1. Install Unity (use the version specified in `UnityProject/ProjectSettings/ProjectVersion.txt` for best compatibility).
2. Open the `UnityProject` folder in Unity.
3. Before running the game, use the Unity Package Manager (Window → Package Manager) to install these packages:
	- **Cinemachine**
	- **ProBuilder**
	- **Text Mesh Pro**
